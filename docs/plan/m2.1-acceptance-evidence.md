## 3. Kubernetes 与界面闭环

E2E 从空 PVC 创建 `agentx-e2e` Namespace，Migration Job 完成后 MySQL、Redis、ClickHouse、MinIO、Platform API、Web 和 Echo MCP 全部 Ready。测试结束后 Namespace 和临时 PVC 已自动删除。

Playwright 通过真实界面按钮完成并断言：

1. 企业 Bootstrap、管理员登录和 Workflow 创建。
2. Credential 创建、改名以及过期 Version 的 `409` 冲突。
3. Model Deployment Revision、Alias 切换历史和价格版本。
4. Echo MCP 连接测试、Tool 发现、Policy 更新和 Debug Invoke。
5. SSRF 阻断、连接失败和错误提示。
6. Skill 目录和 Markdown 创建、相对引用、文件上传、删除取消/确认、版本发布和只读预览。
7. Workflow 画布 MCP Tool 节点连线、独立授权、资源校验、Version 和 Deployment。
8. 中文/English、浅色/深色，以及临时密码和 Member 访问 MCP 的 RBAC 拒绝。
9. 统一资源授权列表通过资源类型 Tab 覆盖 Credential、Model、MCP Server、MCP Tool、Skill、RAG 和 Memory，并验证 Tab 切换、Department/Workflow 授权及撤销取消、确认。
10. 根 `SKILL.md` 通过独立描述输入和富文本正文编辑，保存后后端同步 Skill 元数据并生成必填的 `name`、`description` frontmatter。
10. Model 初始 `untested`、手动连接测试和配置变更后的状态失效；MCP 输入/输出 Schema 字段树；Skill 富文本 Markdown 编辑；长 Dialog 自适应布局。
