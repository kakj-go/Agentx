## 2. 前端行为

- `/evaluations` 只保留“评测报告”和“评测方案”两个视图。
- 新建评测方案可以在一个 Dialog 中配置多条评分规则，创建后生成不可变 v1。
- Evaluation Run 选择明确的 Profile Version。
- `PrerequisiteAction` 在缺少依赖时保持按钮可点击，列出已满足和缺失项；有权限时提供下一步入口，无权限时提示联系管理员。
- 首批覆盖 Application、Application Deployment、Evaluation Run、Workflow 发布、Dataset Version、Skill 启用和 Model 编辑。
