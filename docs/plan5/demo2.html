设计要点（对齐 Dify）

  • 节点卡片：固定 240px 宽，圆角 16px 白卡，头部 = 24px 彩色图标方块 + 标题 + 运行状态；图标颜色即分类色（逻辑青 / 转换蓝 / 集成紫）。
  • 连接点：左入右出的 3px 竖条，对齐头部图标高度；分支类节点（条件 / 审批）不画默认出点，每个分支行右侧各一个连接点，边从分支行直接拉出。
  • 条件分支：节点体即条件摘要（变量 + 操作符 + 值），多条件间显示 AND/OR 徽标；配置面板为可视化条件构建器，变量用「来源节点 · 字段」胶囊。
  • 循环处理：参照 Dify 迭代改为容器节点——内部嵌子流程（迭代开始 → 循环体节点），可拖拽调整尺寸；内置 item / index，并行度与失败策略收进配置面板，替代原来的图环回连。
  • 合并：参照变量聚合器，左侧堆叠多个输入连接点，下游只需接一次。
  • 审批：参照人工介入——每个动作按钮 = 一条分支行，超时走独立分支。
  • AI 附件槽：工具 / 技能 / 知识 / 记忆不再是画布上的独立节点，而是智能体节点上的内嵌槽位——节点体显示附件徽标行，配置面板集中管理，减少画布噪音。
  • 开始 / 结束：开始节点列出输入字段与类型；结束节点即输出变量表，允许存在多个。
  • 子流程：引用不可变的已发布版本，输入输出显式映射，面板一键跳入子流程画布。
  • 变量选择器：所有引用上游输出的字段统一为 节点名 · 字段 胶囊，点击弹出按上游节点分组的变量面板，按类型过滤。

与原设计的差异

  • 画布节点收敛到 13 种（含起始 / AI / 输出），原 30+ 种回到 Dify 同量级。
  • AI 附件不再是画布节点：工具 / 技能 / 知识 / 记忆收进智能体节点的附件槽，画布上不再出现附件节点与虚线连接。
  • 错误处理不再是独立节点：每个节点统一带 error 端口，接 error 边即失败分支，无需失败策略配置；错误与返回由工作流完成模式统一解释。
  • filter/sort/limit 三节点合一，配置面板内分页承载。
