# V2-07A Kubernetes 生产形态证据

状态：`in_progress`。本文件只记录已经实际完成的实现和静态验证，不把尚未运行的外部 TLS Kubernetes E2E 记为通过。

## 已实现

- Production Profile 强制外部 MySQL/Redis/S3/ClickHouse/Vault/OpenSandbox/Prometheus、TLS CA、固定 Egress CIDR、existing Secret 和镜像 digest。
- `deploy-v2.ps1` 支持 Control、Runtime、Observability 独立 Validate/Render/Install/Upgrade/Status/Rollback/Uninstall/Doctor；Production 不渲染 bundled StatefulSet。
- 应用 Pod 使用非 root、只读根文件系统、RuntimeDefault seccomp、Capability Drop、资源 Request/Limit 和不可挂载默认 Token。
- 外部 CA 以 Projected Secret 注入 MySQL、Redis、S3、Vault、OpenSandbox 和 ClickHouse Client。
- `v2-migrate.ps1` 提供独立 Expand/Contract 和唯一 Job；Contract 检查旧 ReplicaSet 与当前/上一协议窗口，并发调用不互相删除，Schema 永不随应用回滚。
- `v2-backup-restore.ps1`、严格 Backup Manifest/Receipt、恢复目标和 Provider Adapter v1 固定 RPO/RTO及 `Backup → Restore → Verify`。
- `v2-07-e2e.ps1` 固定四个临时 Namespace、14 个场景、升级失败回滚、Migration 竞争、网络/Pod 安全、双 `kid`、Control 离线、真实恢复、开发副本恢复和无条件清理流程。
- `deploy-v2.ps1 Status` 输出 Release、Deployment、Migration、Probe、HPA/PDB、Doctor 和外部依赖 CA 状态。
