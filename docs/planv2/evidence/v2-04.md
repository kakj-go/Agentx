## 4. 关键实现与自动化证据

- Runtime Contracts v1 按 V2-04 破坏性策略重写；旧 V2-03 v1 Fixture、未知字段和版本 2 均明确拒绝。
- Bundle/Work Package 固定 Runtime Policy、授权快照、资源闭包和 Worker Compatibility，并保持确定性 JCS Hash 与独立 Ed25519 签名。
- Execution 当前状态、Snapshot、Attempt、Delivery、Checkpoint、终态和 Outbox 在 Runtime MySQL 领域事务中同步提交。
- Worker 使用 30 秒 Attempt Lease、10 秒 Heartbeat、Owner/Fencing/Result Hash 校验；Redis 只承担派发并可由 MySQL 重建。
- Credential Handle 绑定 Tenant、Execution、Node、Attempt、Operation、Resource Version 与 Lease；Vault 或授权失败时无 Control/本地密文回退。
- Sandbox Manager 支持请求取消后的分阶段接管、Provider Label 对账、幂等结果、Terminate 404 收敛和外部 I/O Heartbeat。
- Wait/Approval、Checkpoint/Fork、Evaluation/Debug/Composite、12 维 Quota 和 Retention 均有数据库级唯一性、引用保护和故障恢复测试。
- V2 Runtime Cargo、SQL、Env、Secret 和 NetworkPolicy 边界由 `agentx-boundary-check` 验证，不允许 Legacy Infrastructure、Control Repository、Control 表或 Control Credential 进入 V2 构建产物。
