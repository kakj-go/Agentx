# P6-03 UI SDK与内置节点证据

- `plugin-ui-loader`共享宿主React，按摘要缓存ESM、引用计数CSS，并用Error Boundary隔离Panel/Canvas/Result/Trace renderer。
- Monaco由Web制品本地懒加载，不依赖CDN；插件输出示例使用统一Textarea，在失焦时提交JSON5，避免每次输入重建编辑器。
- UI Host 公开 locale、theme、portalRoot、包内资产、Field/Input/Button/Select/SmartInput，以及可取消的 resolveDefinition/Provider；Panel 接收字段错误、只读状态、Provider Options、Reference Catalog 与资源快照。
- 所有参数面板只发送局部参数patch，Store统一深合并；测试覆盖多个字段连续编辑不互相覆盖。
- 全部节点面板通过`node-panel-registry.tsx`解析，旧`ACTION_PANELS`已删除。停用版本只为已有Draft按精确身份补取，不进入Palette。
- `agentx/data`的Set/List和`agentx/http`的HTTP执行已迁入TypeScript包；旧Rust Set/List/HTTP执行分支和`declarative_http`能力已删除。HTTP通过`ctx.http`复用Rust出口、Credential、Runtime Call和Artifact。
- Runtime Internal API执行`resolveDefinition`和Provider；Control只鉴权和签名转发，不启动Node。模板Provider和resolveDefinition已在安装后端到端调用通过。
- 设计时调用最终采用Runtime Gateway内独立两槽有界进程与十秒同步deadline；请求drop会回收进程树，不创建伪Attempt或持久operation。业务执行仍走Worker Queue/Lease/Fencing。该边界及原因已同步到架构文档。
- 动态解析按参数与上游契约 Hash 缓存并进入 Draft 保存、Version、Debug、评测和 Publisher；Compiler 以节点 ID 冻结实例级端口和输出 Schema。
- 整包版本切换先展示受影响节点、端口、引用和参数，再以单个编辑事务替换；Undo/Redo、只读画布、停用/缺包和断线修复均由统一 Store/注册入口处理。
- 插件 Panel 按包摘要稳定挂载，参数和动态 Manifest 更新通过 Ref 传递，不会卸载插件的搜索状态；CSS 按摘要引用计数回收。
