- Node Manifest 协议为 3.0，插件包、SDK API 和 Runner RPC 均为 1。Node.js 固定为 24.20.0，pnpm 固定为 11.9.0。
- 设计时 `resolveDefinition` 和 Provider 最终使用 Runtime Gateway 内独立、两槽、有界、十秒 deadline 的 Node 进程，不创建持久 Attempt；业务执行仍使用 Queue、Lease 与 Fencing。该实现保证 Control 不执行 Node，也避免设计时流量占满业务 Worker。

## 2. 最终产品闭环

真实验收完成以下连续路径：

`下载模板 → 仓库外目录开发/构建 → check/test/build/pack:plugin → 页面导入 ZIP → Catalog 出现节点 → 画布拖拽和连线 → React 面板配置 → 自动保存和重开 → Draft Debug/发布 → Rust Worker 启动 Node Runner → 下游引用插件输出 → 标准 Trace 与插件内容展示 → v2 导入、设默认、显式切换、停用、下载和引用保护删除`

页面安装测试使用真实文件选择器、按钮和 React Flow Handle，不以数据库或对象存储直写代替用户操作。新增业务插件安装后无需重建 Web 或 Rust 镜像；Workflow 固定包 ID、版本和摘要，Worker 从 Runtime 冻结制品执行。
