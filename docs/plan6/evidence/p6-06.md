# P6-06 开发模板证据

管理页下载的ZIP包含根`AGENTS.md`、字段级Node/UI/Runtime/Trace/Testing文档、锁文件、vendored SDK类型、正式Runner、JSON Mapper和HTTP/Trace示例。

命令实际可运行：`dev`、`check`、`test`、`build`、`pack:plugin`。`test`先编译，再通过正式Runner握手和执行。打包脚本固定ZIP时间、权限和排序，同一输入摘要稳定。

模板和仓库都声明`pnpm@11.9.0`，锁文件通过Corepack复现；模板不使用`workspace:`依赖或宿主私有路径。

临时 Kubernetes 测试把下载 ZIP 解压到 Agentx 仓库之外的独立临时目录，修改成 `acme/ai-variant@1.1.0`，增加过滤/重命名运行逻辑、UI 文案和同步协议测试，再运行 `pnpm install --frozen-lockfile` 及完整命令链。测试检查无 `workspace:` 或宿主绝对路径依赖，并由真实页面导入同一变体产物执行。

正式 SDK/UI 声明通过 TypeScript 生成到模板 vendor，`tests/acceptance/test_plugin_sdk_template_drift.py` 阻止类型、版本、文档链接和 vendored 声明漂移；CI 的完整 pytest 入口自动覆盖导出 ZIP、仓库外变体、打包与页面导入。
