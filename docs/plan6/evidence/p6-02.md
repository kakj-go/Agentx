# P6-02 管理与生命周期证据

- 管理页提供列表、详情、内置包只读展示、导入预览、版本、摘要、启停、默认版本、引用、下载和删除。
- 错误ZIP返回`PLUGIN_PACKAGE_INVALID`；同摘要重复导入/确认幂等；同包版本不同摘要返回`PLUGIN_VERSION_CONFLICT`；并发确认只创建一个版本。
- v1/v2同时安装，更新默认版本不改现有Draft；Studio显式切换到v2时保留参数并进入Undo/Redo事务，v2真实执行输出`pluginVersion=2.0.0`。
- 停用后精确版本从Catalog移除；历史Manifest仍按bundle digest读取；引用中的版本删除返回`PLUGIN_VERSION_IN_USE`；重新启用与默认版本均使用乐观Revision。
- Draft 保存、Version、Deployment、Application 发布、Debug、Fork、子 Workflow 和评测共用插件 Manifest 闭包；新发布只接受启用且 complete 的版本，冻结 Deployment 与进行中 Execution 继续执行。
- 保存与删除使用共享/排他行锁关闭竞态；引用统计包含 Draft、Version、Deployment、生产 Bundle 和 Work Package。失败导入、取消对象和孤儿对象由 retention 角色处理 TTL/GC。
- 历史 Trace 通过 Execution 授权端点读取冻结 Manifest/renderer；普通设计者可查看和使用已启用节点，但不能导入、下载或管理包。
