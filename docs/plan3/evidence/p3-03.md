## 1. 契约与生产链路

- Runtime 契约：`crates/agentx-runtime-contracts/src/workspace.rs`，生成的 JSON Schema 位于 `schemas/runtime-v1/`，内部 OpenAPI 为 `openapi/runtime-internal-v1.json`。
- Core Registry：`crates/agentx-agent-core/src/tool.rs`。无 Workspace Sandbox 时为空；有 Sandbox 时固定且仅包含 `read/write/edit/bash`。
- Worker Adapter：`services/agentx-v2-runtime/src/worker_runtime_agent_core.rs`。Worker 只注入 `ToolPort`，不访问宿主文件系统或启动宿主进程。
- Sandbox Manager：`services/agentx-v2-runtime/src/sandbox_workspace.rs`，提供 `sandboxes:acquire`、`sandboxes:tool`、`sandboxes:release`，并由既有 Reaper 回收过期 Workspace。
- 持久状态：Runtime 初始 Schema 的 `sandbox_workspaces`；没有 migration、双写、兼容层或 fallback。
- Tool Intent/Settlement：复用 `runtime_calls`。`read` 为 `idempotent`；`write/edit/bash` 为 `irreversible`，Effect 已发送后不得重放。
- 大响应：复用 Runtime Artifact 外置路径；Core 只保留 Artifact Reference 与 `truncated`，内联结构结果上限 64 KiB。

Workspace Identity 固定隔离 Tenant、Application/Invocation、Session、稳定 Agent Node Key 和精确 Sandbox Profile Version。Agent Workspace 与 MCP Runtime Sandbox 不共享 Workspace、Lease、Credential、NetworkPolicy 或 Process Session。

## 5. E2E 发现并关闭的问题

- OpenSandbox/Kubernetes metadata label 不接受 `profile:1`：改为固定 Profile Version SHA-256 label，同时保留原始精确版本于 Runtime State。
- Workspace UPSERT 遗漏 `fencing_token` bind，MySQL 8.4 返回 `1835 Malformed communication packet`：补齐绑定并由真实 Manager E2E 复验。
- Application Workspace 的数据库 TTL 曾延长但 Provider TTL 未续期：接入 OpenSandbox `renew-expiration`，续期失败进入明确不可用状态。
- Sandbox Runtime Call 曾把所有工具标成 `idempotent`：现按 Tool Name 固化，`write/edit/bash` 为 `irreversible`，`sent`/`unknown_outcome` 不可重放。
- Bash 环境变量白名单只静默丢弃：改为 Core 调用前拒绝，并由 Manager 防御性返回 `AGENT_BASH_POLICY_DENIED`。
