# P3-02 Agent Core 最小生产垂直切片证据

状态：`done`

## 已落地

- `agentx-agent-core` 被加入 Workflow Worker 的正式 Cargo 依赖。
- `NodeCapability::Agent` 生产入口只调用 `agentx-agent-core::AgentCore::run`。
- Worker 在领取 Attempt 时把已签名执行快照中的 `CompiledAgentNodeV2` 复制到命名空间 `_agent`，因此 Model、Session Policy、Bundle/Definition Hash 和 Attachment 边界不依赖 Control Plane 回读。
- Worker 侧 `ProviderModelPort` 将 Core 的 Context Projection 映射为 OpenAI-compatible Chat Completions，并复用现有 Provider Egress、Vault Credential、Runtime Call Ledger、Usage/价格计算和 Unknown Outcome 分类。
- P3-02 的最小 StatePort 约束已由 P3-05 的破坏性切换收口为 `agent_session_entries`、`agent_session_registers`、`agent_session_operations` 和 `agent_session_usages`；Register 使用 `state_version + fencing_token` 做 CAS，避免旧 Worker 覆盖新 Session 状态。
- `invocation` 使用 Attempt 派生的临时 Session；`application_session` 使用可信 Application Session ID，缺失时返回 `AGENT_SESSION_REQUIRED`。
- P3-02 明确拒绝 Canvas Attachment 和 Workspace Sandbox：`AGENT_ATTACHMENT_RUNTIME_UNAVAILABLE`、`AGENT_WORKSPACE_SANDBOX_RUNTIME_UNAVAILABLE`。
- 旧临时 Loop 已从 `worker_runtime.rs` 物理删除；生产路径不存在运行时分支、Feature Flag、影子执行或 fallback。
- Bundle 2.0 的 Runtime 初始 Schema 校验已同步为 `schema_version=2`，控制面离线时 Worker 仅依赖冻结 Bundle 执行。
- Model Effect 使用稳定 Operation/Effect/Idempotency 身份；恢复同一 prompt 时只做 Ledger/Session 对账，不重复调用 Provider。
- `invocation` 与 `application_session` 的真实 Runtime Slice 均通过；后者验证同一 Application Session 的两次 Execution 能延续消息上下文。
- Budget、Cancel、Deadline、Event Backpressure、Unknown Outcome 和 Core Event→Trace 脱敏映射已接入 Worker。
