## 冻结语义

- Agent 必须有一个精确版本 Model Inspector Reference；旧 Model Canvas Binding 不再生成。
- Workspace Sandbox 是 Inspector 内部 `0..1` Reference；缺失时 `coreTools=[]`，不会授权或注册 `read/write/edit/bash`。
- 选择 Workspace Sandbox 时只派生四个 Core Tool，全部引用同一 Sandbox Version；MCP Attachment 与四工具重名会编译失败。
- MCP、Skill、Knowledge、Long-term Memory 仍是 Canvas Attachment。Agent Workspace Sandbox 与未来 stdio MCP Runtime Sandbox 不混用。
- Bundle 外层 wire contract 已切换为 `ExecutionSpecBundleV2` / `schemaVersion=2`；Work Package 继续使用独立的 V1 版本常量。
- 保存、发布、构建阶段拒绝缺 Model、缺 Session Policy、错误 placement、重复 Inspector Reference、旧 Definition/Manifest。
