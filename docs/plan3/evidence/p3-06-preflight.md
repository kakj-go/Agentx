## Legacy-contract candidate scan

The following matches are intentionally classified as negative tests, historical
test artifacts, or documentation rather than executable compatibility paths:

- Definition 5.0 appears in tests that assert old definitions are rejected and
  in checked-in Playwright reports generated by previous runs.
- Model Inspector references use exact `resourceVersionId` without
  `bindingId`/`bindingRole`; canvas attachments retain both fields by contract.
- `streamable_http`, `sse`, and `stdio` are the active tagged MCP transport
  implementation. No flat transport compatibility parser was identified.
- `RuntimeCommand`/`ActivationManifestV1` are active runtime control contracts
  and must not be conflated with the retired Agent contracts.

After P3-05 closes, P3X-001 should first remove stale generated Playwright
reports and obsolete negative fixtures only where the deletion ledger identifies
them. P3X-002 can then re-run this scan against production source, tests,
schemas, OpenAPI, and deployment manifests separately so historical Plan3
evidence is not mistaken for an executable reference.
